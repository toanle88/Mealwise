# Security policy / Chính sách bảo mật

## Supported version / Phiên bản được hỗ trợ

The latest code on the default branch (`main`) is supported. There are no tagged releases yet.

Phiên bản mới nhất trên nhánh mặc định (`main`) được hỗ trợ. Hiện chưa có bản phát hành được gắn tag.

## Reporting a vulnerability / Báo cáo lỗ hổng

Please do not disclose vulnerabilities in a public issue. Use GitHub's **Report a vulnerability** option under the repository's **Security** tab when it is available. If private vulnerability reporting is unavailable, contact the maintainer using the contact options on the GitHub profile linked from this repository. Include the affected path, impact, and steps to reproduce, but do not include real household data or secrets.

Vui lòng không công khai lỗ hổng qua issue. Hãy dùng mục **Report a vulnerability** trong tab **Security** của repository nếu tính năng này khả dụng. Nếu không có báo cáo riêng tư, liên hệ maintainer qua các cách liên hệ trên hồ sơ GitHub được liên kết với repository. Nêu đường dẫn bị ảnh hưởng, tác động và các bước tái hiện; không gửi dữ liệu gia đình thật hay thông tin bí mật.

We will acknowledge reports as soon as practical, investigate them, and coordinate a fix and disclosure with the reporter.

Chúng tôi sẽ phản hồi sớm nhất có thể, điều tra và phối hợp với người báo cáo để sửa lỗi và công bố thông tin phù hợp.
